# Artificial Intelligence Practical Programs 🤖

This repository contains the implementation of Artificial Intelligence practical programs for Third Year Computer Engineering (TE), Savitribai Phule Pune University (2019 Pattern).

The programs are implemented in Python and cover important AI search algorithms, optimization techniques, machine learning concepts, and problem-solving approaches.

## 🚀 Practical List

### Practical 1: Breadth First Search (BFS) and Depth First Search (DFS)
Implementation of graph traversal algorithms to search all vertices in a graph.

**Concepts Covered:**
- Graph representation
- Queue and Stack
- Recursive traversal
- Search strategies

### Practical 2: A* Search Algorithm
Implementation of A* algorithm for finding the shortest path.

**Concepts Covered:**
- Heuristic function
- Path cost
- Priority queue
- Optimal search

### Practical 3: AO* Algorithm
Implementation of AO* algorithm for AND-OR graph problem solving.

**Concepts Covered:**
- AND-OR graphs
- Heuristic search
- Cost optimization

### Practical 4: Constraint Satisfaction Problem
Implementation of constraint-based problem solving.

**Concepts Covered:**
- Variable assignment
- Constraints
- Backtracking

### Practical 5: Selection Sort / Optimization Techniques
Implementation of optimization and sorting techniques.

**Concepts Covered:**
- Search optimization
- Performance analysis

### Practical 6: Machine Learning / Expert System
Implementation of AI-based classification or expert systems.

**Concepts Covered:**
- Knowledge representation
- Decision making
- Learning models

## ⚙ Installation

Clone the repository:

git clone <your-repository-link>

Move into project folder:

cd AI-Practicals

Install dependencies:

pip install -r requirements.txt

## ▶ Running Programs

Run any practical:

python filename.py

Example:

python Practical_1_BFS_DFS.py
